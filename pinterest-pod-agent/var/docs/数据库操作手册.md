# Pinterest Pod Agent — 数据库操作手册

> **连接信息**
> - Host: `localhost` · Port: `5432`
> - Database: `pinterest_pod`
> - User: `postgres` · Password: `123456`

---

## 表关系总览

```
social_account (账号)
    ├── account_policy   (发帖策略, 1:1)
    ├── publish_job      (发帖内容, 1:N)
    ├── scheduled_task   (调度任务, 1:N)
    ├── pin_performance  (发布绩效, 1:N)
    └── reply_record     (评论回复, 1:N)

campaign (营销活动)
    ├── publish_job      (1:N)
    ├── scheduled_task   (1:N)
    └── pin_performance  (1:N)

publish_job ──发布成功──→ pin_performance (通过 pin_performance_id 关联)
scheduled_task ──引用──→ publish_job (通过 payload_json 里的 job_id)
```

核心流程：`social_account` 绑定账号 → `campaign` 定义活动 → `publish_job` 填发帖内容 → `scheduled_task` 设定执行时间 → 调度器自动执行 → 发布成功写入 `pin_performance`。

## 1. pin_performance — Pin 绩效

> 记录已发布 Pin 的内容和 Pinterest 互动数据。EvoMap 引擎读取此表分析高效策略。

| 字段                | 类型                   | 必填  | 默认值    | 说明 |
|---------------------|------------------------|-------|-----------|------|
| `id`                | 整数(自增)             | 是    | 自动      | 主键 |
| `account_id`        | 文本(64)               | 否    | —         | 发布该 Pin 的账号 ID |
| `campaign_id`       | 文本(64)               | 否    | —         | 所属活动 ID |
| `pinterest_pin_id`  | 文本(128)              | 否    | —         | Pinterest 平台的 Pin ID。非空时唯一 |
| `board_id`          | 文本(128)              | 否    | —         | 所属 Board ID |
| `product_type`      | 文本(80)               | 否    | —         | 产品类型，如 poster、canvas、mug |
| `niche`             | 文本(120)              | 否    | —         | 利基市场，如 home decor、fashion |
| `title`             | 文本(160)              | 是    | —         | 发布时使用的标题 |
| `description`       | 长文本                  | 是    | —         | 发布时使用的描述 |
| `destination_url`   | 文本(1024)             | 否    | —         | 跳转链接 |
| `image_url`         | 文本(1024)             | 否    | —         | 图片 URL 地址 |
| `content_prompt`    | 长文本                  | 是    | —         | 生成内容时使用的 LLM 提示词，用于 EvoMap 分析 |
| `visual_prompt`     | 长文本                  | 否    | —         | 生成图片时使用的提示词 |
| `model_name`        | 文本(160)              | 否    | —         | 使用的 AI 模型名，如 deepseek-v4-flash |
| `prompt_version`    | 文本(40)               | 是    | v1        | 提示词版本号，追踪 prompt 迭代效果 |
| `keywords`          | JSON 数组              | 是    | []        | 关键词列表，如 ["dog mom","gift"] |
| `strategy_snapshot` | JSON 对象              | 是    | {}        | 生成时的策略配置快照，用于后期归因分析 |
| `impressions`       | 整数                   | 是    | 0         | 曝光次数。所有比率的分母 |
| `saves`             | 整数                   | 是    | 0         | 收藏数 |
| `clicks`            | 整数                   | 是    | 0         | 点击数 |
| `outbound_clicks`   | 整数                   | 是    | 0         | 外链点击数 |
| `comments`          | 整数                   | 是    | 0         | 评论数 |
| `reactions`         | 整数                   | 是    | 0         | 互动数 |
| `ctr`               | 浮点数                 | 是    | 0         | 点击率 = clicks / impressions |
| `save_rate`         | 浮点数                 | 是    | 0         | 收藏率 = saves / impressions |
| `engagement_rate`   | 浮点数                 | 是    | 0         | 互动率 = (saves+comments+reactions) / impressions |
| `published_at`      | 时间戳(带时区)          | 否    | —         | Pin 在 Pinterest 上的发布时间 |
| `metrics_updated_at`| 时间戳(带时区)          | 否    | —         | 互动数据最后更新时间 |
| `content_hash`      | 文本(64)               | 否    | —         | 内容去重哈希，系统自动生成 |
| `title_hash`        | 文本(64)               | 否    | —         | 标题去重哈希，系统自动生成 |
| `description_hash`  | 文本(64)               | 否    | —         | 描述去重哈希，系统自动生成 |
| `content_batch_id`  | 文本(64)               | 否    | —         | 内容批次 ID，批量生成时共享 |
| `variant_angle`     | 文本(160)              | 否    | —         | 变体角度，如 gift_idea、seasonal_trend |
| `created_at`        | 时间戳(带时区)          | 是    | 当前时间   | 记录创建时间 |
| `updated_at`        | 时间戳(带时区)          | 是    | 当前时间   | 记录最后修改时间 |

**综合评分：** `feedback_score = ctr × 0.5 + save_rate × 0.3 + engagement_rate × 0.2`，分数越高说明内容效果越好。

| `platform`       | 文本(40)        | 是    | pinterest | 平台标识 |
| `account_id`     | 文本(64)        | 否    | —         | 关联账号 ID |
| `campaign_id`    | 文本(64)        | 否    | —         | 关联活动 ID |

| `priority`       | 整数           | 是    | 0         | 优先级 0-10，越大越优先 |

| `error_type`     | 文本(40)        | 否    | —         | 错误分类：retryable / fatal / final_failed |
| `created_at`     | 时间戳(带时区)   | 是    | 当前时间   | 记录创建时间 |

### task_type 枚举

| 值                   | 功能           | 说明 |
|----------------------|----------------|------|
| `warmup_and_publish` | 暖机+发帖       | 先模拟浏览再发帖，最常用 |
| `publish`            | 纯发帖          | 直接发帖，不做暖机 |
| `warmup`             | 仅暖机          | 只模拟浏览，不发帖 |
| `generate_image`     | 生成图片        | 调用 Fal.ai 生成营销图片 |
| `generate_video`     | 生成视频        | 调用 API 生成营销视频 |
| `auto_reply`         | 自动回复        | 检查新评论并自动回复 |
| `refresh_trends`     | 刷新趋势        | 更新 Pinterest 趋势关键词 |
| `cleanup`            | 清理资源        | 清理过期临时文件 |
| `reclaim_stale`      | 回收任务        | 把卡在 running 状态的任务回收为 pending |

### status 枚举

| 值          | 含义     | 说明 |
|-------------|----------|------|
| `pending`   | 待调度    | 等待到达 scheduled_at 后被拣选 |
| `ready`     | 已锁定    | 调度器已获取，正在发送到队列 |
| `running`   | 执行中    | Worker 正在执行 |
| `completed` | 已完成    | 通用任务成功 |
| `published` | 已发布    | 发帖任务成功（专用） |
| `failed`    | 失败      | 重试耗尽或不可恢复错误 |
| `cancelled` | 已取消    | 手动取消 |

### payload_json 参数

| 参数                       | 类型    | 必填  | 说明 |
|----------------------------|---------|-------|------|
| `account_id`               | 文本    | 是    | 用哪个账号执行 |
| `job_id`                   | 文本    | 是    | 对应 publish_job.job_id |
| `warmup_duration_minutes`  | 整数    | 否    | 暖机时长(分钟)，默认 5 |
| `dry_run`                  | 布尔    | 否    | 试运行，true 则不实际发布 |

## 9. reply_record — 回复记录

> 记录 Pinterest 评论及其 AI 生成的自动回复。account_id + comment_id 组合唯一，防止重复回复。

| 字段             | 类型           | 必填  | 默认值      | 说明 |
|------------------|----------------|-------|-------------|------|
| `id`             | 整数(自增)      | 是    | 自动        | 主键 |
| `account_id`     | 文本(64)        | 是    | —           | 所属账号 ID |
| `comment_id`     | 文本(120)       | 是    | —           | Pinterest 评论 ID。与 account_id 组合唯一 |
| `pin_url`        | 文本(1024)      | 否    | —           | 评论所在 Pin 的 URL |
| `author_name`    | 文本(240)       | 否    | —           | 评论者用户名 |
| `comment_text`   | 长文本          | 是    | —           | 评论原文 |
| `reply_text`     | 长文本          | 否    | —           | AI 生成的回复内容，可手动修改 |
| `status`         | 文本(40)        | 是    | suggested   | suggested(待审) / posted / skipped / failed |
| `safety_status`  | 文本(40)        | 是    | safe        | safe / risky / blocked |
| `safety_reason`  | 长文本          | 否    | —           | 安全审核未通过的原因 |
| `posted_at`      | 时间戳(带时区)   | 否    | —           | 实际回复发布时间 |
| `raw_json`       | JSON 对象       | 是    | {}          | Pinterest API 原始返回数据 |
| `created_at`     | 时间戳(带时区)   | 是    | 当前时间     | 记录创建时间 |
| `updated_at`     | 时间戳(带时区)   | 是    | 当前时间     | 记录最后修改时间 |

## 10. content_template — 内容模板

> 控制 LLM 生成文案和图片的提示词模板。按 scope(作用域) + template_type(类型) 两级匹配：先精确匹配 niche，匹配不到则 fallback 到 scope=global。

| 字段             | 类型           | 必填  | 默认值    | 说明 |
|------------------|----------------|-------|-----------|------|
| `id`             | 整数(自增)      | 是    | 自动      | 主键 |
| `scope`          | 文本(120)       | 是    | —         | 作用域。global=全局兜底，也可填具体 niche 如 home decor |
| `template_type`  | 文本(40)        | 是    | —         | 类型：title_description / image_prompt |
| `template_text`  | 长文本          | 是    | —         | 模板正文。支持变量：{niche} {product_type} {audience} {season} {offer} {board_name} |
| `is_active`      | 布尔           | 是    | true      | 是否启用，false 则跳过 |
| `created_at`     | 时间戳(带时区)   | 是    | 当前时间   | 记录创建时间 |
| `updated_at`     | 时间戳(带时区)   | 是    | 当前时间   | 记录最后修改时间 |

> scope + template_type 组合唯一。

### 模板变量

| 变量             | 来源                      | 说明 |
|------------------|---------------------------|------|
| `{niche}`        | publish_job.niche         | 利基市场 |
| `{product_type}` | publish_job.product_type  | 产品类型 |
| `{audience}`     | publish_job.audience      | 目标受众 |
| `{season}`       | publish_job.season        | 季节/节日 |
| `{offer}`        | publish_job.offer         | 促销信息 |
| `{board_name}`   | publish_job.board_name    | Board 名称 |

## 调度器工作原理

### 调度流程

```
Celery Beat (每 10 分钟触发)
    │
    ▼
扫描 scheduled_task: status=pending 且 scheduled_at ≤ now()
    │
    ▼
对每条记录做 3 项检查（查 account_policy）：
    ├── ① cooldown_until > now()       → 跳过
    ├── ② 今天已发数 ≥ daily_max_posts → 跳过
    └── ③ 当前时间不在时间窗口内        → 跳过
    │
    ▼ (全部通过)
发送到 Celery 队列 → Worker 领取执行
```

### Worker 发帖步骤

```
① 通过 AdsPower 打开指纹浏览器
② 导航到 Pinterest pin-creation-tool 页面
③ 等待上传区域渲染
④ 选择图片上传
⑤ 等待图片处理完成
⑥ 填写标题
⑦ 填写描述
⑧ 选择目标 Board
⑨ 点击 Publish
⑩ 轮询检测发布成功（最多 20 秒）
```

### 状态流转

```
scheduled_task:
  pending → ready → running → completed / published
    │                    │
    │                    ├── 可重试 → pending (attempt_count +1)
    │                    └── 重试耗尽 → failed
    └── cancelled

publish_job:
  pending → running → published
                └── failed
```

### 需要运行的服务

| 服务          | 用途           | 启动命令 |
|---------------|----------------|----------|
| Redis         | 消息队列和锁    | `redis-server` |
| Celery Worker | 执行任务        | `celery -A app.celery_app:celery_app worker` |
| Celery Beat   | 定时触发调度    | `celery -A app.celery_app:celery_app beat` |
| Uvicorn       | REST API       | `uvicorn app.main:app` |

### 关键环境变量 (.env)

| 变量                                | 说明 |
|-------------------------------------|------|
| `SCHEDULER_ENABLED=true`            | 启用调度器 |
| `SCHEDULER_AUTO_DISPATCH_ENABLED=true` | 启用自动分发 |
| `PUBLISH_INTERVAL_MINUTES=10`       | 调度扫描间隔(分钟) |
| `SCHEDULER_DRY_RUN=false`           | true=试运行，不实际发布 |

| 步骤 | 表               | 关键字段 |
|------|------------------|----------|

| 改变账号风控状态   | social_account   | risk_status |
